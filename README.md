# Telegram-бот для прохождения теста по коммуникации

Этот проект представляет собой Telegram-бота, разработанного для проведения тестирования навыков коммуникации. 
Бот позволяет пользователям регистрироваться, проходить тест с вопросами и вариантами ответов, а также просматривать статистику прохождения (для администраторов/преподавателей).

## Основные возможности

*   **Регистрация пользователей:** Бот запрашивает имя, фамилию и курс, проверяя корректность ввода.
*   **Прохождение теста:** Пользователь отвечает на вопросы, выбирая один из предложенных вариантов (кнопками или текстом в формате `Ответ 1`).
*   **Сохранение результатов:** Все ответы и итоговый балл сохраняются в локальной базе данных SQLite.
*   **Мониторинг состояния:** Бот периодически отправляет администратору статус-сообщение подтверждая, что он работает.
*   **Просмотр ответов:** После завершения теста пользователь может нажать кнопку "Посмотреть ответы", чтобы увидеть правильные варианты.

## Технологический стек

*   **Python 3.12+**
*   **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API.
*   **aiosqlite** — асинхронная библиотека для работы с SQLite.
*   **python-dotenv** — для загрузки переменных окружения (токен бота, ID админов).

## Как запустить локально

### 1. Клонирование репозитория
Склонируйте проект на свой компьютер:
```bash
git clone https://github.com/Fargetik/TG-Bot-for-completing-test_communication-module.git
cd TG-Bot-for-completing-test_communication-module
```

### 2. Создайте и активируйте виртуальное окружение:
Windows:
```bash
python -m venv .venv
.venv\Scripts\activate
```
MacOs/Lunix
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей
Установите все необходимые библиотеки из файла requirements.txt:
```bash
pip install -r requirements.txt
```

### 4. Настройка окружения (Секреты)
Для работы бота нужны токен и ID администраторов. Никогда не храните их в коде!

В корне проекта создайте файл с именем .env.

Добавьте в него следующие строки:
```bash
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id,id_другого_админа
```

### 5. Запуск бота
запустите главный файл:
```bash
python bot.py
```

## Важное замечание

Бота можно перенастроить на самом деле под любой вид тестов. поменяв всего в одном файле вопросы и ответ (в questions.py)
+ можно довести бота до серверного состояния и запускать его на постоянной основе, если необходимо
